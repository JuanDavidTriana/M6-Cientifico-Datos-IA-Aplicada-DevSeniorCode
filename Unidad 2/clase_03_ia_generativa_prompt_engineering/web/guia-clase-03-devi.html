El proyecto Devi: una asistente para DevSenior Code

Durante las Clases 3 y 4 construimos Devi, la asistente virtual de la academia, como lo haría un equipo de IA de verdad: por versiones. Toca cada versión para ver cómo funciona por dentro.

Nota docente · ¿cómo se construye un ChatGPT?

1. Preentrenamiento (billones de tokens) → modelo base. 2. SFT (conversaciones de ejemplo) → modelo instruct. 3. RLHF/DPO (preferencias humanas) → asistente.

Devi v1 es el paso 2 en miniatura sobre GPT-2. Devi v2 usa un modelo que ya pasó por los 3 pasos (Qwen3) y lo controla con el prompt.

Nota docente · RAG de verdad (Unidad 3)

En vez de TF-IDF se usan embeddings y una base de datos vectorial, los documentos se parten en fragmentos y se evalúa si el buscador trae el texto correcto. Si el buscador falla, el LLM responde mal aunque sea excelente.

El modo pensar (celda B4.6) ayuda en preguntas que exigen razonar sobre el contexto, como el horario según el país, a cambio de tiempo.

Devi v1 vs Devi v2

Devi v1

GPT-2 ajustado. El conocimiento vive en los pesos: memoriza frases, pero mezcla e inventa.

Devi v2

Qwen3 + system prompt + contexto. El conocimiento vive en un documento: se actualiza editándolo.

Prompting

Rol, tarea, reglas, formato y una salida para el "no sé".

Few-shot y JSON

Aprender de ejemplos sin entrenar y devolver datos que el código pueda usar.
